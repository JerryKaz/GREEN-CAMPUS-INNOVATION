# Photos and videos

Put files in this folder using the exact names below. They appear on the site automatically.

Until your own photo exists, each spot shows a **stand-in stock photo** from Unsplash (free to use under the Unsplash License). These are illustrative only and are not photos of Valley View University. To switch the stand-ins off and show designed placeholders instead, set `USE_STOCK = false` in `assets/js/lib/media.js`.

To see every slot labelled with its file name on the live pages, open any page with `?media=1` at the end of the address (for example `index.html?media=1`). Use `?media=0` to hide the labels again.

## Videos

## Research gallery

The photo gallery on the Research page is managed from Admin, then Photo Gallery, where each upload gets its caption, date, time, location and description. Uploads are resized and have GPS data removed automatically.

Only use original photographs taken for this project, and get consent before publishing photos of identifiable people.
